# durov.dog

Static landing page for the **durov.dog** parody memecoin.

Single-file `index.html` — no build step, no dependencies. Just open in a browser.

## Deploy

- **GitHub Pages:** Settings → Pages → Deploy from `main` branch, root.
- **Vercel / Netlify / Cloudflare Pages:** import repo, no build config needed.
- Any static host serving `index.html`.

## Notes

- `dog.png` is referenced in the certificate hero — add the mascot artwork here (or replace with any 500×500 transparent PNG).
- Contract address is placeholder `COMING SOON — beware of fakes`; edit `#ca` in `index.html` at launch.
- Social links in footer are placeholders (`href="#"`) — update before ship.
